# Dist Scraper Tool

A TypeScript CLI tool for scraping content from Astro's `/dist/` folder and generating an updated `llms.txt` file for AI-SEO optimization.

## Overview

This tool extracts meaningful content from your built Astro site (HTML files in the `/dist/` folder), converts it to clean markdown format, and generates a comprehensive `llms.txt` file following the industry-standard specification for Large Language Models.

## Features

- **HTML Content Extraction**: Parses HTML files and extracts semantic content
- **Markdown Conversion**: Converts HTML to clean, well-formatted markdown
- **Content Categorization**: Automatically organizes content by type (core pages, blog posts, case studies, etc.)
- **Link Preservation**: Maintains internal links with proper URL formatting
- **Content Filtering**: Excludes navigation, footers, and non-content elements
- **Preview Mode**: Shows generated content without writing files
- **Verbose Output**: Detailed progress tracking and debugging information

## Installation

From the project root:

```bash
pnpm tools:setup
```

This will:
1. Install dependencies for the dist-scraper tool
2. Build the TypeScript source code
3. Make the tool ready for use

## Usage

### Generate llms.txt

```bash
# Generate llms.txt from current dist folder
pnpm tools:scrape

# Preview what would be generated (without writing file)
pnpm tools:scrape:preview

# Generate with custom options
cd project_tools/dist-scraper
pnpm start generate --output ../../custom-llms.txt --verbose
```

### Validate Dist Folder

```bash
# Check if dist folder is ready for scraping
pnpm tools:validate
```

### Full Build with LLMs Update

```bash
# Build → Generate llms.txt → Rebuild (to include updated llms.txt)
pnpm build:with-llms
```

## Command Options

### `generate` command

- `-o, --output <path>` - Output file path (default: `./public/llms.txt`)
- `-p, --preview` - Preview mode without writing file
- `-v, --verbose` - Show detailed processing information
- `-d, --dist-path <path>` - Path to dist folder (default: `./dist`)
- `-u, --base-url <url>` - Base URL for the site
- `-n, --site-name <name>` - Site name for the header
- `-s, --site-description <desc>` - Custom site description

### `validate` command

- `-d, --dist-path <path>` - Path to dist folder to validate
- `-v, --verbose` - Show detailed file listing

## How It Works

1. **Scanning**: Recursively scans the `/dist/` folder for HTML files
2. **Filtering**: Excludes non-content files and navigation elements
3. **Extraction**: Extracts meaningful content using Cheerio HTML parsing
4. **Conversion**: Converts HTML to clean markdown using Turndown
5. **Categorization**: Organizes content into sections (core, design, content collections, etc.)
6. **Generation**: Creates a structured `llms.txt` file following the standard format

## Content Categories

The tool automatically categorizes pages into:

- **Core Template Features**: Homepage, About, Contact, Pricing
- **Design System**: Styleguide pages and documentation  
- **Content Collections**: Blog, Case Studies, Products, Team directories
- **Sample Content**: Individual blog posts, case studies, etc.
- **Landing Pages**: Marketing and campaign pages
- **Additional Features**: Other template functionality

This tool is part of the comprehensive AI-SEO implementation in the ARDA Astro Template, which includes:

## Workflow Recommendation

1. **Development**: Make content changes in your Astro source files
2. **Build**: Run `pnpm build` to generate the static site
3. **Scrape**: Run `pnpm tools:scrape` to update `llms.txt` with latest content
4. **Rebuild**: Run `pnpm build` again to include the updated `llms.txt` in your dist folder
5. **Deploy**: Your site now has the most current AI-optimized content

Or use the convenient combined command:
```bash
pnpm build:with-llms
```

## Troubleshooting

**"Dist folder not found"**: Run `pnpm build` first to generate the dist folder.

**"No HTML files found"**: Ensure your Astro build completed successfully and generated HTML files.

**"Failed to extract content"**: Some HTML files may have unexpected structure. Check verbose output for details.

**Empty llms.txt**: Verify your dist folder contains the expected HTML files and that content extraction is working properly.
